# Marlon Vinicius | Consórcio e Patrimônio

Landing page responsiva com pré-simulador de consórcio e encaminhamento de leads
para o WhatsApp comercial.

## Requisitos

- Node.js 20 ou superior
- npm

## Desenvolvimento local

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Build de produção

```bash
npm run build
npm run preview
```

## Tecnologias

- Nuxt 4
- Vue 3
- Tailwind CSS 4
